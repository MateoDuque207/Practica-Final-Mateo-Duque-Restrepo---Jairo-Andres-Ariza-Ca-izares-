# Parser de Notación FEN para Ajedrez
Este proyecto corresponde a la **Práctica Final ** del curso **Lenguajes y Paradigmas de computación**

El objetivo es implementar un parser en Python para validar cadenas FEN (Forsyth-Edwards Notation) de ajedrez según la gramática BNF especificada. El programa hace análisis léxico y sintáctico de la cadena ingresada, y si es válida, dibuja el tablero de ajedrez. Si hay errores, muestra mensajes indicando qué está mal.
